Introduction to WhatsOmni

Complete Multi-Tenant B2B Omnichannel SaaS Platform

WhatsOmni is an enterprise-grade multi-tenant B2B conversational operating system that unifies omnichannel customer messaging, visual flow automation, 3 configurable AI operational models (BYOK, Master Fixed, Master Selectable), deal CRM pipelines, multi-host calendar booking, and automated e-commerce cart recovery into a single command center.

The Unified Operations Architecture

Modern businesses typically juggle 6–9 disconnected software subscriptions: a WhatsApp marketing tool, an Instagram DM manager, a Calendly appointment scheduler, a third-party AI chatbot builder, an e-commerce cart recovery plugin, and a standalone CRM like HubSpot or Salesforce.

WhatsOmni unifies every layer of customer communication and automation into a single platform: every customer message across 8 channels, AI-generated answer, appointment booking, deal stage movement, and cart recovery event connects seamlessly into one real-time contact timeline.

1. The 3 AI Operational Models

WhatsOmni provides an adaptable, multi-tier AI Operational Architecture that empowers Super Admins to control LLM credentialing, compute liability, and end-user model flexibility:

Mode 01
Bring Your Own Key (BYOK)
Zero Platform Compute Cost
Tenants supply their own API keys for any supported provider (OpenAI, Claude, Gemini, Groq, DeepSeek, xAI, Mistral, or self-hosted Ollama). Credentials are stored encrypted per-tenant.
  • Key Source: Supplied by tenant workspace
  • Token Billing: Paid direct to AI provider
  • Model Scope: All models on tenant's account
Strategic SaaS Fit
Self-serve and low-subscription SaaS pricing tiers where you capture 100% software margins with zero LLM billing exposure.
Mode 02
Master Key (Platform Fixed)
Frictionless Turnkey Onboarding
The Super Admin configures master API keys in the Control Plane and locks a single default provider and model (e.g. OpenAI gpt-4o-mini or DeepSeek deepseek-chat) for all workspaces.
  • Key Source: Super Admin Master Key
  • Token Billing: Absorbed / metered via plans
  • Model Scope: Standardized default LLM
Strategic SaaS Fit
Turnkey non-technical client onboarding where businesses get instant AI automation out-of-the-box without creating developer keys.
Mode 03
Master Key (User Selectable)
Tiered Multi-Model Catalog
The Super Admin configures master API keys and enables a curated catalog. Tenants can freely choose which model powers each specific agent, flow node, or inbox copilot.
  • Key Source: Super Admin Master Keys
  • Token Billing: Plan quotas & add-on credits
  • Model Scope: Curated multi-model catalog
Strategic SaaS Fit
Premium tiers where power users switch between ultra-fast models (Groq / Llama 3) and deep reasoning models (Claude 3.5 Sonnet / GPT-4o).

Setup MySQL Database & Redis

Create the MySQL 8.0 relational database schema and verify the in-memory Redis message broker connection.

WhatsOmni relies on MySQL 8.0 (or MariaDB 10.11+) with full utf8mb4 multibyte character support to store multi-tenant records, visual flow graphs, and message transcripts. In-memory Redis is used as the asynchronous queue broker and WebSockets cache store.

Create MySQL Database

Log in to your MySQL terminal client or server CLI and create the dedicated database instance with strict UTF-8 collation:

Terminal 
mysql -u root -p -e "CREATE DATABASE whatsomni_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
Automatic Database Creation in Laravel 11
You can skip manual database creation entirely. When you run php artisan migrate during configuration, Laravel 11 automatically detects if the database does not exist on your MySQL server and prompts: "The database whatsomni_db does not exist on the mysql connection. Would you like to create it? (yes/no)". Simply press Enter (yes) and Laravel will automatically create the database with full utf8mb4_unicode_ci support and execute all migrations for you.

Verify Redis Service Connection

Ensure that the Redis server daemon is running and listening on default port 6379:

Terminal 
redis-cli ping
# Expected response: PONG

Database-Driven Email Engine via Super Admin Control Plane

In WhatsOmni, transactional email dispatch is managed dynamically through the Super Admin Control Plane and stored encrypted in the database. You do not need to modify static .env files or restart backend server processes to change mail providers or update credentials.

Super Admin GUI Configuration
All email dispatch parameters are managed in the Super Admin panel under Settings → Mail Configuration. Configuration changes take effect immediately at runtime across all tenant registration flows, password resets, and calendar notifications.

Setup Option 1: Resend API (Recommended)

Resend provides ultra-fast delivery, real-time analytics, and verified domain reputation without legacy SMTP overhead:

  • Create a free account at resend.com.
  • Navigate to Domains and add your sending domain (e.g., yourdomain.com). Add the provided DKIM and SPF DNS records to your DNS provider (Cloudflare, GoDaddy, Route53, etc.).
  • Go to API Keys and create an API key with Full Access permissions (starts with re_...).
  • Log in to your WhatsOmni Super Admin Dashboard, navigate to Settings → Mail Configuration, and select Resend as the driver:
    • API Key: Paste your re_... API token.
    • From Address: Enter your verified sending email (e.g., notifications@yourdomain.com).
    • From Name: Enter your brand/platform name (e.g., WhatsOmni).
  • Enter your personal email in the Test Recipient input and click Send Test Email to verify the connection live.
  • Click Save Settings to activate.

Setup Option 2: Custom SMTP Server Relay

If you use a traditional transactional SMTP relay provider (such as Amazon SES, Postmark, SendGrid, Mailgun, Brevo, or a private Postfix server):

  • Log in to your WhatsOmni Super Admin Dashboard and navigate to Settings → Mail Configuration.
  • Select SMTP as the mail driver and fill in your relay parameters:
    • SMTP Host: Your mail server hostname (e.g., smtp.mailgun.org or email-smtp.us-east-1.amazonaws.com).
    • SMTP Port: 587 (for TLS / STARTTLS) or 465 (for SSL).
    • Encryption: Select TLS, SSL, or None.
    • Username: Your SMTP username or API user.
    • Password: Your SMTP password or relay secret key.
    • From Email Address: The sender address verified on your SMTP account.
    • From Sender Name: The sender display name visible in the inbox.
  • Enter your email into the Test Recipient box and click Send Test Email. WhatsOmni will attempt an immediate live SMTP handshake and confirm success.
  • Click Save Settings to persist your configuration.

For high-throughput enterprise messaging with green badge verified numbers:

  • Go to Meta for Developers → WhatsApp → API Setup.

    Callback URL: https://api.yourdomain.com/api/webhooks/channel/{connection_id} (where {connection_id} is the channel connection ID shown on your channel setup screen)

  • Subscribe to the messages webhook topic.
